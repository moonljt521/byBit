# SOL Solana

## 它是什么

Solana 是 2020 年主网上线的高性能公链，主打"快和便宜"：出块极快、单笔转账费用不到 0.001 美元，被称为"以太坊杀手"之一。

## 关键事实

- **共识机制**：PoS + 独创的 PoH（历史证明）时间戳机制
- **性能**：理论数万 TPS，是 Visa 的数十倍
- **生态**：DeFi、NFT、Meme 币发行活跃；曾因 FTX 崩盘重挫，后强势复苏
- **特点**：使用 Rust 系语言写合约（非 Solidity）

## 高性能的代价

Solana 曾多次因网络负载过高而**整体宕机**数小时——用中心化程度更高的设计换性能，这是"不可能三角"（去中心化/安全性/性能）的典型取舍。

## 风险提示

网络稳定性历史记录一般；生态代币波动极大，Meme 币占比高，散户容易接盘。
