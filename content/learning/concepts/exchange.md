# 交易所是怎么运作的

## 中心化交易所（CEX）

币安、OKX、Bybit 都是 CEX。它的核心组件和本模拟盘一模一样：

1. **账户体系**：注册、登录、KYC（实名认证）
2. **行情系统**：聚合买卖盘价格，推送实时行情（本项目接 OKX/Binance 公开行情）
3. **撮合引擎**：订单簿按"价格优先、时间优先"撮合买卖。C++/Rust 是主流（追求每秒百万笔）；本项目用 Go 实现同样的算法
4. **账务系统**：复式记账，每一分钱的进出都有流水可查（本项目的 ledger 表）
5. **风控系统**：合约的保证金监控、强平引擎（本项目的 futures engine）

## 交易所靠什么赚钱

- **手续费**：现货 taker 约 0.1%、maker 更低；合约约 0.02%-0.05%
- 上币费、杠杆利息、理财利差等

## CEX vs DEX

| | CEX（币安等） | DEX（Uniswap 等） |
|---|---|---|
| 托管 | 交易所管钱 | 智能合约管钱，私钥自持 |
| 撮合 | 订单簿 | 自动做市商 AMM（资金池定价） |
| KYC | 需要 | 通常不需要 |
| 风险 | 交易所跑路/被盗 | 合约漏洞/无常损失 |

## 本项目的位置

你正在用的 CryptoSim 是一个**完整仿真的 CEX 模拟盘**：行情是真实的，撮合/账务/风控逻辑是仿真的，资金是虚拟的。理解了它，你就理解了币安的骨架。
