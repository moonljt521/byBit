# 杠杆与强平

## 杠杆的本质：借钱放大仓位

10x 杠杆开多 = 你出 100 USDT 保证金，交易所"借"你 900，共 1000 USDT 的 BTC 仓位：

- BTC 涨 10% → 你赚 100 = **保证金翻倍**
- BTC 跌 10% → 你亏 100 = **保证金归零**

盈亏都按仓位名义价值计算，杠杆只是放大器。

## 逐仓 vs 全仓

- **逐仓（Isolated）**：每个仓位独立保证金，爆了只亏这个仓位的钱。本项目采用逐仓
- **全仓（Cross）**：全部余额共用保证金，抗波动能力强，但爆起来亏全部

## 强平（Liquidation）

交易所不会让你亏到欠钱，所以设了**强平线**：

1. 你的仓位权益 = 保证金 + 未实现盈亏
2. 权益 ≤ 维持保证金（约仓位的 0.5%）→ 触发强平，系统强制平仓
3. 爆仓后你基本拿不回钱（剩余价值归保险基金）

**近似强平价公式（逐仓）**：

- 做多：开仓价 × (1 − 1/杠杆 + 0.5%)
- 做空：开仓价 × (1 + 1/杠杆 − 0.5%)

| 杠杆 | 做多强平距离（约） |
|---|---|
| 2x | -50% |
| 5x | -19.5% |
| 10x | -9.5% |
| 20x | -4.5% |
| 100x | -0.5% |

## 为什么合约新手必爆

加密货币日常波动就有 3-10%，20x 杠杆下一次普通波动就到强平线。**"高杠杆 + 不设止损 + 重仓"是爆仓三件套**，模拟盘里请亲自体验一次 20x 爆仓，比读一百篇文章都有效。

## 本项目强平引擎的实现

合约引擎每秒检查所有持仓：`保证金 + 未实现盈亏 ≤ 维持保证金` 即强平，标记价格取 OKX 实时价——和真实交易所的.mark price 逻辑一致。
