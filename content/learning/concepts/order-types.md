# 订单类型：限价单与市价单

## 市价单（Market Order）

"立刻按当前市场价成交，多少价格我都接受。"

- 优点：确定性——一定成交
- 缺点：成交价不可控，行情剧烈时会付出**滑点**代价
- 本项目实现：按最新价 ±0.05% 滑点立即全额成交

**什么时候用**：止损逃命、追强势突破、不在乎一两个点的快进快出。

## 限价单（Limit Order）

"只在我不高于 X 的价格买 / 不低于 Y 的价格卖。"

- 优点：价格可控，还能当 maker 吃更低费率
- 缺点：可能不成交——价格没到你挂的位置就踏空
- 本项目实现：挂单后，当真实市场价穿越你的委托价时自动分批成交

**什么时候用**：计划好价位的高抛低吸、大额分批建仓。

## 真实交易所还有

- **止损单 / 止盈止损单**：触发条件单，到价自动转市价/限价——合约玩家的保命工具
- **Post-Only**：强制挂单方（maker），保证不会被立即成交
- **冰山单 / TWAP**：大单拆小，减少冲击成本

## 订单簿（Order Book）

左右两栏的买卖挂单列表：绿色买单（Bids）、红色卖单（Asks），按价格排序。中间的差距叫**点差（Spread）**。买卖档越厚，市场越深，大单进出滑点越小。

本项目盘口展示的是 OKX 真实十档深度，可以直接观察 BTC/ETH 的流动性有多"厚"。
