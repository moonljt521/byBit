# 现货 vs 合约

## 现货（Spot）

"一手交钱一手交货"：用 USDT 买 BTC，你就是真的持有 BTC（在交易所的账本里）；卖出换回 USDT，交易结束。

- **只能做多**（涨了才赚钱）
- **没有到期日**，拿着就行
- 最大损失 = 本金（币归零也只亏买入成本）
- 资金占用 = 全额（买 1 万美元 BTC 就要 1 万美元）

## 永续合约（Perpetual Futures）

不实际持有币，而是**押注价格方向**的衍生品，用保证金交易：

- **可做多也可做空**：做空 = 先"借币"卖出，跌了买回来还
- **杠杆**：10x 杠杆 = 1000 USDT 保证金撬动 10,000 USDT 的仓位，盈亏都放大 10 倍
- **无到期日**（区别于交割合约），但通过**资金费率**锚定现货价
- **强平机制**：亏损吃掉保证金就强制平仓（见杠杆与强平篇）

## 一张表看懂

| | 现货 | 永续合约 |
|---|---|---|
| 方向 | 只能做多 | 多空皆可 |
| 杠杆 | 无 | 1-125x |
| 最大损失 | 本金 | 全部保证金（可能瞬间） |
| 持有成本 | 无 | 资金费率 |
| 适合 | 长期持有、新手 | 对冲、短线、老手 |

## 本项目的建议路径

1. 先用现货完成 10 笔完整交易（下单→成交→卖出），熟悉流程和手续费
2. 用 1-2x 杠杆开一次多单，观察浮盈亏和强平价怎么变化
3. 试着开一个 20x 空单，感受"价格动 5% 就接近爆仓"的恐惧——**这就是模拟盘存在的意义**
