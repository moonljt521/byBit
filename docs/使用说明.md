## 二、五个页面怎么用

### 行情页

7 个主流币的实时价格（5 秒刷新）：最新价、24h 涨跌、最高最低、成交量。**点击任意一行**直接跳到该币的交易页。刚入门建议先点开「学习中心」把 8 个币的百科读完。

### 现货交易页（核心）

三栏布局，和 Bybit 一样：

- **左栏**：盘口（十档买卖挂单）+ 实时成交流——感受市场跳动
- **中栏**：K 线图。切换 1m~1d 周期；鼠标悬停看某分钟的开高低收和成交量；MA5/10/30/60 是均线，价格在均线上方偏强
- **右栏**：下单面板

**下单流程**（建议第一单）：

1. 选「限价单」，方向选「买入」
2. 价格填**低于当前价 2%** 的数（比如现价 78000 就填 76440）
3. 数量填 0.001（约 78 USDT，最小下单金额 5 USDT）
4. 点「买入 BTC」→ 提示已提交
5. 看「当前委托」：你的单在排队（这笔钱已被**冻结**）
6. 等价格跌到 76440 → 引擎自动**分批成交**（可能分好几笔）
7. 成交后去「资产」页：你会看到 BTC 余额，USDT 减少

**几个真实规则**：

- 买单冻结 `价格×数量×1.001`（含 0.1% 手续费），卖单冻结币
- 撤单立刻解冻
- 市价单按最新价 ±0.05% 滑点**立即成交**
- 每次成交都有手续费（0.1%），在成交记录里能查

### 合约交易页（高风险，先看后玩）

和现货最大的区别：**可以赌跌（开空）、可以加杠杆、会爆仓**。

- **开多（看涨）/ 开空（看跌）**：选方向 → 杠杆滑块（1-20x）→ 数量 → 开仓
- 开仓即扣**保证金 + 手续费**（逐仓模式）
- 仓位表实时显示：标记价、未实现盈亏、收益率、**强平价**
- 价格碰到强平价 → 引擎直接爆仓，保证金归零（每秒检查一次）
- 每 8 小时结算一次资金费率（多头付空头 0.01%）
- 点「平仓」按当前标记价结算盈亏

**新手必做实验**：用 20x 杠杆开一单，然后看着强平价离价格只有 4.5%——这就是为什么真实市场每天有人倾家荡产。

### 资产页

各币种的可用/冻结余额。点右上角头像 →「重置账户」可清空全部恢复到 10,000 USDT（历史流水保留）。

- **币种百科**：BTC/ETH/USDT/BNB/SOL/XRP/TRX/DOGE 各一篇，讲是什么、怎么运作、风险在哪

- **术语词典**：46 个术语中英对照，随时搜索

## 四、常见问题（FAQ）

**Q: 行情不动了？**
后端行情链路是 OKX → Binance → 内置模拟行情三级降级。都断时会切到模拟行情（价格随机波动）。本机需要代理才能访问 OKX，后端要用 `SIM_HTTP_PROXY=http://127.0.0.1:26002` 启动。

**Q: 下单报「订单金额太小」？**
最小下单金额 5 USDT（和真实交易所一致），把数量调大一点。

**Q: 限价单一直不成交？**
只有市场价**穿越**你的委托价才会成交：买单挂高于现价、卖单挂低于现价立即成交；反之就是等着。可以挂个离现价 1% 的单观察分批成交过程。

**Q: 数据库想清空重来？**
```bash
psql postgresql://cryptosim:cryptosim@127.0.0.1:5432/cryptosim -c \
"TRUNCATE trades, spot_orders, funding_records, futures_positions, ledger_entries, balances, users RESTART IDENTITY CASCADE;"
```

**Q: 端口被占用？**
后端 8080 / 用户端 5173 / 管理后台 5174，改端口分别对应 `SIM_HTTP_ADDR`、`frontend/vite.config.ts`、`admin/vite.config.ts`。
